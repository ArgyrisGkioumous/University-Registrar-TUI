# 🏫 University Registrar TUI

Μια native εφαρμογή σε **C++** για τη διαχείριση των μελών και των μαθημάτων ενός πανεπιστημίου, χρησιμοποιώντας ένα διαδραστικό περιβάλλον κειμένου (**TUI - Text User Interface**) βασισμένο στη βιβλιοθήκη `ncurses`.

## 🚀 Χαρακτηριστικά
* **Διαδραστικό Μενού (TUI):** Πλοήγηση στο μενού με τη χρήση των βελών του πληκτρολογίου χάρη στην `ncursesw`.
* **Αντικειμενοστραφής Σχεδιασμός (OOP):** Πλήρης αξιοποίηση του πολυμορφισμού και της κληρονομικότητας (Base κλάση `Member` και υποκλάση `Professor`).
* **Μόνιμη Αποθήκευση (Persistent Storage):** Αυτόματη εγγραφή και αποθήκευση των δεδομένων σε δομημένο αρχείο μορφής `CSV`.
* **Υποστήριξη Wide Characters:** Πλήρης συμβατότητα με ελληνικούς χαρακτήρες στο τερματικό.

## 🛠️ Τεχνολογίες & Βιβλιοθήκες
* **Γλώσσα:** C++20
* **Σύστημα Build:** CMake
* **Βιβλιοθήκες:** `ncursesw` (για το γραφικό περιβάλλον τερματικού)

## 📁 Δομή Project
* `main.cpp` - Η ροή της εφαρμογής και η σχεδίαση του μενού TUI.
* `Registrar.h / .cpp` - Η κλάση διαχείρισης του συστήματος (καταχωρήσεις, αρχεία CSV).
* `Member.h / .cpp` - Abstract κλάση για τα μέλη του πανεπιστημίου.
* `Professor.h / .cpp` - Υποκλάση που κληρονομεί από τη `Member`.
* `Course.h / .cpp` - Κλάση για τη διαχείριση των μαθημάτων.
